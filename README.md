# Mini Shell in C (Codecrafters)

A minimal Unix-like shell written in **C**, built as part of the **Codecrafters Shell Challenge**.

This shell supports:
- Built-in commands
- Running external executables
- Input parsing with quotes + escapes
- Output redirection
- Pipelining
- Tab-autocompletion (builtins + executables in PATH)
- Command history
- History persistence
- Interactive terminal raw-mode input handling using backspace, tab & arrows
